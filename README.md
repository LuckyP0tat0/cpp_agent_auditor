# cpp_agent_auditor

Мультиагентная система аудита C++ кода и поиска уязвимостей на основе LangGraph, Advanced RAG и локальных LLM через Ollama.

## Описание (Суть проекта)

Основная цель проекта — автоматизировать процесс аудита безопасности (code review) для языка C++, сфокусировавшись на поиске уязвимостей и ошибок логики. 

Вместо использования классических статических анализаторов (SAST), которые часто выдают ложные срабатывания, здесь применяется **мультиагентный ИИ-подход**:
1. **Поиск контекста (RAG)**: Перед анализом система сканирует предоставленный код и извлекает из локальной векторной базы (на основе справочника уязвимостей CWE) наиболее релевантные описания возможных проблем.
2. **Анализ с опорой на стандарты**: LLM-модель (Reviewer) анализирует код не "вслепую", а опираясь на конкретные паттерны уязвимостей, подтянутые на шаге RAG. Это значительно снижает галлюцинации нейросети.
3. **Система сдержек и противовесов**: Специальный Агент-критик (Critic) проверяет работу ревьюера. Если отчет получился недостаточно подробным, поверхностным или неточным, критик отправляет его на доработку (до 3 итераций). Этот цикл (координируемый графом LangGraph) гарантирует глубокую проверку.

Важной особенностью системы является то, что все процессы могут выполняться локально и приватно благодаря использованию LLM-сервера **Ollama**, без необходимости отправки исходного кода в сторонние API.

## Архитектура
Система построена в виде графа выполнения (LangGraph) со следующими узлами:
- **Retriever**: Ищет релевантные правила и паттерны (CWE) из векторной базы данных для заданного участка кода.
- **Reviewer**: Анализирует исходный код на основе найденных правил и предоставляет первичное ревью.
- **Critic**: Оценивает качество ревью от Reviewer'а, и при необходимости отправляет его на доработку (поддерживается до 3 итераций улучшений).

## Установка и запуск

1. Установите необходимые зависимости. Проект использует виртуальное окружение `venv`.
2. Установите и запустите локальный сервер [Ollama](https://ollama.com/) с необходимой моделью:
   ```bash
   ollama run llama3
   ```
3. Запустите основной скрипт графа:
   ```bash
   python graph.py
   ```
